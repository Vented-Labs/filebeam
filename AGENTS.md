Backend work follows `backend/AGENTS.md`.

## Local Files

- `.filebeam/` at the repository root is gitignored scratch space for plans, notes
  and throwaway output. Put anything that should not be committed there, not in
  `PLAN.md`, `notes/`, `tmp/` or a tool-specific folder.
- Search tools skip ignored paths, so read `.filebeam/` directly when you need an
  earlier plan.
- Nothing in `.filebeam/` belongs in a commit, PR description or code comment.
  Restate what matters instead of pasting it.
